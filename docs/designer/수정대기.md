# simple properties 패널 변경 요청
## 심플 프로퍼티 패널 전체 
각 항목에 한국어로 설명이 있으면 좋겠어.

## Options source 는 무조건 static으로 고정하면 되니까 선택하는 것이 안보이게 해줘
- checkbox
- radio group
- select
- tag list

## Imave View 항목 추가 요청
- Image Source, Alternative text

## Table 항목 추가 요청
 - Header items 항목 추가

 ## Tree
 - 트리를 하나 집어넣으면 아주 간단한 예(아래 form-js 블럭 참고)로 초기화 시켜줘.

 ## Tab
 - Tab 컴포넌트에서는 Default Value가 필요없어. 이것은 안보이게 해줘.
 - Orientation은 넣어줘. 

```form-js
{
  "components": [
    {
      "type": "tree",
      "label": "접힘 기본",
      "dataSource": "=[{\"label\":\"부모\",\"children\":[{\"label\":\"자식1\"},{\"label\":\"자식2\"}]}]",
      "id": "tree3",
      "expandedByDefault": false,
      "layout": {
        "row": "Row_0f3057x"
      }
    }
  ],
  "type": "default",
  "id": "Tree_test_3",
  "schemaVersion": 19
}
```

## 차트 변경 요청
 - 제목이 너무 왼쪽에 붙어 있네. Group 과 동일하게 조정해줘.
 - 차트의 크기가 폭의 크기로만 정해지는데 높이도 같이 봐야해. 높이, 폭 모두 차트 크기에 영향을 받게 해줘.
## Card
