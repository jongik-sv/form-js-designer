# 나중에 수정할 것
- 입력 창을 가지는 것들을 묶어서 형태 변경이 가능하도록 할것
- 사용자 프로퍼티 추가
- 마크다운에 랜더링 되는 플러그인(mermaid 처럼), 수정 모듈도 있으면 좋겠다.
- 컴포넌트 스페이싱 조절
- 전체 컴포넌트의 패딩, 마진값을 조정할 수 있는 기능 추가(Form 의 프로퍼티에 넣으면 전체 동일하게 적용)


# 완료
- 아웃라인은 위에 햄버그 아이콘으로 접을 수 있게 해줘.
- delete / insert
- 드래그할 때 컨테이너 좌우에 플래이스 홀더가 너무 빨리 나와. 나는 안에 넣고 싶은데 너무 빨리 나와서 위치가 자꾸 흔들림. 컨테이너 옆의 플래이스홀더는 좀 늦게 나오면 좋겠다.  
- 가장 왼쪽에 잇는 properties, live preview 버튼은 가장 오른쪽에 있는 side-panel 위에 탭 형식으로 선택하게 하자.
- view json (edit 가능) - UI 파일 업로드 기능
- 테이블 Header Items 가 안되는 문제
- 컴포넌트 아래 핸들(draggable=true)을 달아서 높이 설정 기능
- 멀티 선택 기능 탐색 후 기능 추가 (미완성)
- 마진/패딩 반으로 줄이자.(진행중)
- 컴포넌트 더블 클릭해서 label 변경 기능 
- css 최적화
